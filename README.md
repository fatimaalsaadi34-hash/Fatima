### 👩‍💻 نبذة عني | About Me
طالبة في تخصص **هندسة البرمجيات** بجامعة الأمير سطام بن عبدالعزيز، شغوفة ببناء حلول برمجية ذكية وعملية تجمع بين كفاءة الكود وجمال التصميم. أسعى دائماً لتطوير مهاراتي التقنية والعمل على مشاريع تجمع بين البرمجة، الذكاء الاصطناعي، وتجربة المستخدم المتميزة.

* أعمل حالياً على تطوير مشاريع برمجية وأنظمة لإدارة البيانات وتجربة المستخدم.
* مهتمة بمجالات **الذكاء الاصطناعي (AI)** والبرمجيات المستدامة (Green AI).
* أستمتع بتحويل الأفكار إلى واجهات تفاعلية وتصاميم رقمية منظمة.
